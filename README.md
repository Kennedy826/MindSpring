## MindSpring
MindSpring is an online platform offering access to mental wellness articles and personalized therapy sessions to support your journey toward a healthier mind.

## Prerequisites
Make sure you have the following installed on your machine:

Node.js (recommended LTS version)

npm (Node Package Manager) or yarn

## Features
* **User Friendly Interface:** Intuitive and clear UI design for easy navigation and interaction.

## Tech Stack
* **ReactJS:** React is a JavaScript library for building user interfaces
* **Tailwindcss:** This is a utility-first CSS framework for rapid UI development.
* **Framer-motion:** It is used for smooth, declarative animations in React.
  
## Installation
To run MindSpring locally, follow these steps:

1. Clone this repository to your local machine:
   
`https://github.com/Kennedy826/MindSpring.git`

2. Navigate to the project directory:

`cd MindSpring`

3. Install dependencies for the client:

```
# Install client dependancies

npm install
npm install tailwindcss @tailwindcss/vite
npm i framer-motion

## Usage

2. Start the client:

npm run dev
```
